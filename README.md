# CoreSpace

Website built from the CoreSpace Figma design.

Next.js (App Router) + TypeScript + CSS Modules. No CSS framework — the design
is pixel-specified, so the styles carry the Figma values directly.

## Running it

```bash
npm install
npm run dev      # http://localhost:3000
```

`npm run dev` and `npm run build` both run `sync-assets` first, which copies
`assets/` into `public/assets/` so Next can serve it.

## Layout

```
app/                 routes, fonts, global styles
components/
  DesignFrame/       the 1440x800 frame the design is drawn on
  SiteHeader/        nav bar          — Figma 183:3224
  Hero/              hero section     — Figma 183:3165
assets/              Figma exports (source of truth, see assets/README.md)
public/assets/       generated by sync-assets, gitignored
measure.mjs          diffs the rendered hero against the Figma numbers
```

## Design parity

The hero reproduces Figma node `183:3165` at 1440x800. Elements carry a
`data-node-id` attribute naming the Figma node they came from, and `measure.mjs`
uses those to diff every box, origin and gap against the design:

```bash
npm run build && npx next start -p 3100   # in one shell
node measure.mjs                          # in another
```

All boxes, text origins and gaps currently match Figma exactly.

Below 1440px the frame scales down as a whole rather than re-flowing, which
holds every padding and margin at its designed ratio. That is a stopgap —
replace it with real breakpoints once tablet and mobile frames exist in Figma.
